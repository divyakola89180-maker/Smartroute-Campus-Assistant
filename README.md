# Smartroute-Campus-Assistant

Real-time campus bus tracking system with live location, route timings & nearest stop finder | HTML, CSS, JS, Google Maps API

## Features
- Live bus location tracking for students
- Route-wise bus timings display
- Admin panel to add / update bus routes
- Driver panel to update live location
- Nearest bus stop finder

## Tech Stack
- Frontend: HTML, CSS, JavaScript
- API: Google Maps API

## Project Structure
- Bus Tracking/index.html - Student main page
- Bus Tracking/admin.html - Admin dashboard
- Bus Tracking/driver.html - Driver location update page
- Bus Tracking/app.js - Main application logic
- Bus Tracking/style.css - UI styling

## How to Run
1. Clone the repository
   git clone https://github.com/divyakola89180-maker/Smartroute-Campus-Assistant
2. Open Bus Tracking/index.html in your browser
3. Add your Google Maps API key in app.js
